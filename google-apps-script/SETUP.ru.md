# Подключение форм к Google Sheets

1. Открой нашу Google-таблицу и выбери **Расширения → Apps Script**.
2. Замени содержимое `Code.gs` кодом из приложенного файла Code.gs, сохрани проект. В настройках проекта → Script properties добавь SPREADSHEET_ID со значением ID своей таблицы.
3. В списке функций выбери `setup`, нажми **Выполнить** и предоставь разрешение на работу с таблицей.
4. Нажми **Развернуть → Новое развертывание → Веб-приложение**.
5. **Выполнять от имени: Я**. **У кого есть доступ: Все / Anyone**. Нажми **Развернуть**.
6. Скопируй URL веб-приложения, заканчивающийся на `/exec`, и пришли его в этот чат.

Это открывает только обработчик приёма заявок. Таблица остаётся приватной, API не позволяет читать лиды. Для интервью установлен лимит 100 новых заявок в день; записи с одинаковым requestId не дублируются. Используй вымышленные данные. Это демонстрационный приёмник, не промышленная CRM: перед реальным запуском нужны защита от спама, политика обработки данных и защищённая общая админка.

После получения URL я установлю его только на сервере сайта, проверю тестовую запись и опубликую сайт по общедоступной ссылке. Пароли Google и OAuth-токены не нужны.
